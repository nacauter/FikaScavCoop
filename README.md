# Fika Scav Coop

Клиентский плагин для **SPT (Single Player Tarkov)** и мультиплеерного мода **Fika**, снимающий ограничение на совместный вход в рейд игроков разных фракций (**ЧВК / PMC** и **Дикий / Scav**).

**Версия плагина:** `1.0.3`

## Что делает плагин

В стандартной версии Fika клиентский интерфейс браузера рейдов (`MatchMakerUIScript.RefreshUI`) блокирует кнопку подключения, если выбранная фракция игрока не совпадает с фракцией хоста.

**Fika Scav Coop** с помощью Harmony-патча временно выравнивает отображаемую сторону матча при отрисовке списка сессий, благодаря чему:
* Игрок за **Дикого** может присоединиться к лобби, созданному **ЧВК** (и наоборот).
* Остальные проверки совместимости Fika (совпадение карты, времени суток и статуса загрузки хоста) продолжают работать как обычно.

> **Важно при обновлениях Fika:** Если после выхода нового патча Fika внутренние поля `Fika.Core.dll` изменятся, плагин **не вызовет вылет игры** — он безопасно отключит свой патч при запуске и выведет предупреждение `patch skipped (version mismatch?)` в лог BepInEx.

## Совместимость

* **SPT:** `4.0.13`
* **Fika.Core:** `2.2.3`
* **Fika Server:** `2.2.1`
* **Требования:** [BepInEx 5](https://github.com) (входит в комплект SPT) и плагин `com.fika.core`.

## Установка

1. Скачайте актуальную версию **`FikaScavCoop.dll`** со страницы [Releases](https://github.com) (или соберите из исходников).
2. Скопируйте файл **`FikaScavCoop.dll`** в папку с клиентскими плагинами игры:
   ```text
   <Папка с игрой>\BepInEx\plugins\
   ```
3. Установите плагин игроку, который подключается к рейду за другую фракцию (рекомендуется поставить всем участникам кооператива).
4. Серверная модификация не требуется.

## Как использовать

1. **Хост** выбирает фракцию (например, **ЧВК**), локацию и время суток, создает лобби Fika и ожидает на экране запуска рейда.
2. **Клиент** выбирает другую фракцию (**Дикий**), ту же локацию и то же время суток.
3. В списке рейдов Fika нажимает кнопку входа, после чего хост запускает матч.

## Устранение неполадок

| Проблема | Возможная причина | Решение |
| :--- | :--- | :--- |
| Кнопка входа в рейд другой фракции по-прежнему заблокирована | Плагин не загрузился или лежит не в той папке | Убедитесь, что `FikaScavCoop.dll` находится строго в `BepInEx\plugins\`, а в файле `BepInEx\LogOutput.log` есть строка `Fika Scav Coop 1.0.3 loaded!`. |
| В `LogOutput.log` появилась ошибка `Fika: expected fields not found — patch skipped (version mismatch?)` | Установлена неподдерживаемая версия `Fika.Core` | Проверьте соответствие версии `Fika.Core` (`2.2.3`). Игра продолжит работать в штатном режиме, но для новой версии Fika потребуется обновление плагина. |
| Кнопка входа неактивна при совпадении карты, но хост уже в игре | Хост уже запустил рейд (`IN_GAME`) | Плагин разрешает вход в лобби до начала матча (статус `COMPLETE`). Дождитесь, пока хост создаст новое лобби. |
| Не совпадает локация или время суток | Выбраны разные карты или разное время (день/ночь) | Выберите у клиента ту же локацию и то же время суток, что и у хоста. |

## Удаление

1. Закройте клиент игры.
2. Удалите файл **`FikaScavCoop.dll`** из папки `<Папка с игрой>\BepInEx\plugins\`.
